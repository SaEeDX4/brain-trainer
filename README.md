# Brain Trainer – Web Game

**Brain Trainer** is a fun and interactive web game designed to improve your mental agility through fast-paced math challenges. Built using HTML, CSS, and JavaScript, the app lets users test their speed and accuracy in a beautiful, modern UI.

---

## 🎮 Features

- ✅ Normal Mode with simple math questions
- ✅ Challenge Mode with increasing difficulty
- ✅ Score and time tracking
- ✅ Level progression
- ✅ High score tracking using localStorage
- ✅ Responsive design for desktop and mobile
- ✅ Sound effects for correct/incorrect answers
- ✅ Keyboard support for fast play
- ✅ Clean and modern UI/UX

---

## 🧠 Technologies Used

- HTML5
- CSS3 (Flexbox, responsive layout, animations)
- JavaScript (ES6+)

---

## 🚀 How to Run

1. Clone the repo or download the zip
2. Open `index.html` in your browser
3. Choose a game mode and start training your brain!
